# Guides

Follow practical guides for running Nogging with supported agents and session
tools. Start with [Using Nogging with Claude Code](using-with-claude-code.md),
the default agent, or pick the guide for the agent you run.

To follow the work in a browser or on a phone, see the [dashboard](dashboard.md), an
optional read-only web view of Beads, their graph, sessions, tokens, commits and tests.
