# Public project identity decision — 2026-09-10

## Decision

**SpecForge remains the canonical public project name for the first public
release.** Existing repository, CLI, installer, service, configuration, and
package identifiers remain unchanged.

**Agentsembli is only a provisional working name** for a possible wider
ecosystem. It is not a released product, a dependency, or a claim of ownership
over any domain, account, package scope, repository, or trademark. SpecForge
does not require an Agentsembli website or an Agent Console installation.

## Product relationship

- **SpecForge** is the independently usable planning and coordination workflow.
- **Agent Console** is an optional sibling project for orchestration and UI.
- **Agentsembli** may be used provisionally to discuss the possible ecosystem
  containing those projects, but it is not canonical product branding.

## Provenance boundary

SpecForge is conceptually inspired by
[Gas Town](https://github.com/steveyegge/gastown). It is an independent
implementation and does not include or reuse Gas Town runtime components.
[Beads](https://github.com/gastownhall/beads) is currently the only component
adopted from that ecosystem. SpecForge is not affiliated with or endorsed by
the Gas Town or Beads maintainers.

## External claims

No domain, account, package namespace, trademark, website, or repository rename
is required or authorized by this decision. The existing name-research reports
remain point-in-time evidence, not legal clearance or reservations.

A future commercial umbrella-brand decision requires fresh collision and
trademark research, explicit owner approval and claims, and a separate migration
plan if any technical identifier would change.

## Owner record

The Product Owner explicitly selected this no-rename approach in the planning
conversation on 2026-09-10. Final public-release acceptance and the repository
visibility change remain separate human decisions.
