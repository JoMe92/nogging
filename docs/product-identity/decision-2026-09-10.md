# Public project identity decision — 2026-09-10

## Decision

**Agentsembli SpecForge is the canonical public project name.** The repository
moves to `JoMe92/agentsembli-specforge`; the existing CLI, installer, service,
configuration, and package identifiers remain unchanged for compatibility.

Agentsembli is a display-name qualifier, not a separate runtime dependency or
a claim over any domain, account, package scope, or trademark. Agentsembli
SpecForge does not require an Agentsembli website or Agent Console installation.

## Product relationship

- **Agentsembli SpecForge** is the independently usable planning and coordination workflow.
- **Agent Console** is an optional sibling project for orchestration and UI.
- **Agentsembli** may also describe a possible wider ecosystem, without making
  that ecosystem a product dependency.

## Provenance boundary

SpecForge is conceptually inspired by
[Gas Town](https://github.com/steveyegge/gastown). It is an independent
implementation and does not include or reuse Gas Town runtime components.
[Beads](https://github.com/gastownhall/beads) is currently the only component
adopted from that ecosystem. SpecForge is not affiliated with or endorsed by
the Gas Town or Beads maintainers.

## External claims

This decision authorizes the new GitHub repository but does not claim a domain,
account, package namespace, trademark, or website. The existing name-research
reports remain point-in-time evidence, not legal clearance or reservations.

A future commercial umbrella-brand decision requires fresh collision and
trademark research, explicit owner approval and claims, and a separate migration
plan if any technical identifier would change.

## Owner record

The Product Owner selected Agentsembli SpecForge and created its successor
repository on 2026-09-10. Final public-release acceptance and the repository
visibility change remain separate human decisions.
