# Nogging project

## Purpose

Provide a reproducible, low-overhead operating system for agentic software
delivery on a local development host.

## Conventions

- Stable task IDs use `TASK-<AREA>-<NNN>`.
- OpenSpec is written only in planning sessions.
- A task has one Bead mapping via namespaced labels.
- Change lifecycle: `open`, `done`, `archived`.
