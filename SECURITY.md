# Security policy

Nogging is still in its private pre-release phase. If you have
access to this repository and find a vulnerability, contact the repository
owner privately through the contact method associated with their GitHub
profile. Do not open a public issue containing vulnerability details.

When the repository becomes public, the owner will immediately enable and
verify GitHub Private Vulnerability Reporting. The canonical reporting entry
point will then be:

<https://github.com/JoMe92/nogging/security/advisories/new>

General support belongs in the
[issue tracker](https://github.com/JoMe92/nogging/issues), but
suspected security vulnerabilities do not.
